# Syncory

Syncory is a team communication and collaboration platform that brings channels, direct messages, file sharing, and real-time presence to modern product teams.

## Quick Links

- [Product Overview](docs/overview.md)
- [Setup Guide](docs/setup.md)

## Repository Layout

- `backend/` — NestJS API, WebSocket gateway, and background jobs.
- `frontend/` — Next.js client for web users.
- `docs/` — Product and operations documentation.
- `docker-compose*.yml` — Local and production orchestration.

## Getting Started

1. Clone the repository.
2. Copy the example environment files (`.env.example`) into place.
3. Follow the [Setup Guide](docs/setup.md) to run Syncory locally or deploy it.
